GameZone

Biblioteca pessoal de jogos com autenticação, banco de dados e CRUD completo.

1. Apresentação

O GameZone permite ao usuário criar uma conta e gerenciar uma coleção pessoal de jogos.

Público-alvo

Jogadores que desejam organizar informações sobre seus jogos favoritos em um único aplicativo.

2. Tecnologias

  • Flutter e Dart
  • Supabase Auth
  • Supabase PostgreSQL
  • Android Studio / VS Code
  • Git e GitHub
  • HTML e CSS

3. Instalação

  1. Instale o Flutter SDK e o VS Code.
  2. Abra a pasta GameZone no VS Code.
  3. Execute flutter pub get.
  4. Instale o Supabase CLI e o FlutterFire CLI.
  5. Execute flutterfire configure.
  6. Crie ou selecione um projeto Supabase.
  7. Execute flutter run.

4. Estrutura de pastas

lib/
├── models/       # modelos de dados
├── screens/      # telas
├── services/     # Supabase e autenticação
├── widgets/      # componentes reutilizáveis
├── theme/        # identidade visual
└── utils/        # validações

5. Supabase e banco de dados

O Supabase Auth controla as contas. O Supabase PostgreSQL armazena os jogos de cada usuário.

Estrutura:

users
└── {uid}
    └── games
        └── {gameId}
            ├── title
            ├── genre
            ├── platform
            ├── year
            ├── description
            ├── coverUrl
            └── createdAt

As regras de segurança restringem cada usuário aos próprios registros.

6. CRUD

  • Criar: botão “Novo jogo”.
  • Consultar: a tela inicial lista os jogos em tempo real.
  • Editar: menu do card → Editar.
  • Excluir: menu do card → Excluir.

7. Identidade visual

O GameZone utiliza fundo escuro, roxo como cor principal e ciano como destaque. O ícone de controle representa o tema gamer.

Para alterar as cores, edite as constantes em lib/theme/app_theme.dart.

8. Manual de manutenção

Alterar o nome

Edite o título em lib/main.dart e, para o nome exibido no dispositivo, configure também o projeto Android/iOS conforme a plataforma.

Alterar o logo

O logo atual é um componente em lib/widgets/gamezone_logo.dart. Para usar uma imagem, coloque-a em assets/images/ e registre o arquivo no pubspec.yaml.

Adicionar campo ao jogo

Inclua o campo no GameModel, no formulário game_form_screen.dart e no mapa enviado ao Firestore.

Adicionar tela

Crie um arquivo em lib/screens/ e navegue usando Navigator.push.

Gerar nova versão

flutter clean
flutter pub get
flutter build apk --release

9. Problemas comuns

  • Supabase não inicializa: execute novamente flutterfire configure.
  • Login falha: confira se o provedor E-mail/Senha está habilitado no Supabase Auth.
  • Firestore nega acesso: confira as regras do arquivo firestore.rules.
  • Dependências com erro: execute flutter pub get.
